# 退役漫画板块及素材

## Goal

彻底移除 `comics`（漫画梗图）板块及其帖子、上传图片实体和展示入口。

## Requirements

- 通过幂等 Alembic 数据迁移删除 `comics` 板块关联的上传原件、缩略图和数据库记录。
- 删除该板块的主题、帖子、成员关系及板块记录，并清理专属 `漫画` 标签。
- 移除后端固定排序、前端图标/推荐标签/色板和演示内容脚本中的板块引用。
- 保留按 `漫画阅读` 标签触发的通用阅读器能力。
- 不修改 Logo、favicon 或全站配色。

## Acceptance Criteria

- 升级迁移后数据库不再存在 `boards.slug = "comics"`。
- 该板块关联上传的原件和 `_thumbnails` 缓存均被删除。
- API 与前端不再固定展示漫画板块或漫画推荐标签。
- 轻量后端语法检查、Web 类型检查和 diff 检查通过。

## Evidence

- 2026-07-14 正式站点公开 API：板块 ID `32`，主题 ID `116`，2 个帖子。
- 主题首帖引用上传 ID `29` 至 `37`，共 9 张图片。
- 仓库 `apps/web/public` 没有漫画专属静态图片；图片来自上传存储。
