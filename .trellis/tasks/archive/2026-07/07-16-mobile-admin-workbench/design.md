# 移动端管理工作台技术设计

## 边界

- 仅修改 `AdminWorkbenchPanel` 与 `AdminConsoleShell` 的模板/样式，以及一份定向 Playwright 响应式测试。
- 继续使用 `useAdminSystem()`、`useCurrentUser()`、`usePublicSiteSettings()` 和现有路由；不改变 API、缓存键、权限判断、统计口径或后台配置键。
- 正式 Logo、favicon、默认路径及旧值兼容映射保持不变。

## 响应式结构

### 桌面（大于 1120px）

- 保持四列摘要、双栏工作区、四列快捷入口和固定侧栏。
- 不改变内容最大宽度、路由或交互。

### 过渡区（861px–1120px）

- 保持现有两列摘要、单栏工作区与两列快捷入口。
- 桌面侧栏继续生效，避免扩大本次回归面。

### 管理控制台紧凑模式（不大于 860px）

- 保留抽屉、通知入口和六项底部导航。
- 顶栏纳入顶部安全区，压缩非信息性留白；菜单按钮保持至少 44px 触控区域。
- 底栏继续按可见权限项等分，纳入左右/底部安全区；当前项使用现有 soft primary 语义，不新增颜色或入口。
- 内容区预留固定底栏高度，最后一个可操作项不得被覆盖。
- 在 `681px–860px` 利用收起侧栏后释放的横向空间维持四列摘要，避免横屏/小平板退化为稀疏的两行指标。

### 手机内容模式（不大于 680px）

- 页头切成紧凑的“标题 + 短日期”结构，桌面说明文字在手机上省略。
- 四项运营摘要改为 2×2 扫读网格；每项保留真实数值、说明、语义图标和原路由。
- “需要处理”区紧跟摘要，降低页面区块间距；快捷入口保持单列且触控高度不低于 44px。
- 加载骨架与成功态使用相同的 2×2 摘要节奏，避免加载完成后大幅跳动。

### 极窄屏（不大于 360px）

- 继续保持 2×2 摘要，不隐藏指标。
- 缩短可省略的品牌文字，保留官方 Logo、菜单、通知与六个导航入口。
- 活动时间和辅助文本允许紧凑换行或省略，禁止横向滚动。

## 状态与契约

- 加载、请求错误、无待办、有待办、无审计记录和有审计记录全部沿用现有 Vue Query 状态。
- `summaryItems`、`attentionItems`、`recentAuditLogs` 的计算和目标路由不变。
- 只为日期增加手机短格式展示，不改变日期来源和桌面文案。

## 可访问性

- 保留现有 landmarks、标题层级、`role="status"`、`role="alert"`、`aria-current`、抽屉 `inert` 与焦点陷阱。
- 所有移动导航、菜单和快捷入口至少 44×44 CSS 像素。
- 保留 `:focus-visible` 和 `prefers-reduced-motion` 行为；无功能依赖 hover。

## 验证与回滚

- `pnpm typecheck:web` 与 `git diff --check`。
- 使用拦截 API 的 Playwright 定向用例验证 320×844、390×844、860×640 和 1440×900：
  - 核心摘要与下一核心区标题可见；
  - 页面无横向溢出；
  - 移动导航触控尺寸合格；
  - 桌面摘要仍为四列且底栏隐藏。
- 视觉回归时可按文件回滚模板/SCSS；没有数据或迁移回滚需求。
