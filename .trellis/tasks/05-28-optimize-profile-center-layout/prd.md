# 优化个人中心资料页布局

## Goal

在不推翻现有浅蓝网格、头像等级框和成长卡片风格的前提下，把 `/u/:username` 自己访问时的体验优化成更明确的“个人中心”：关键操作更好找，桌面端减少无效留白，移动端降低拥挤感。

## Requirements

- 保留现有资料页数据来源和接口，不改后端契约。
- 自己访问资料页时突出“个人中心”和头像/资料编辑入口；他人访问仍保持公开资料语义。
- 桌面端身份区上移，统计/成长/徽章/设置形成稳定右侧信息栏，避免横向溢出。
- 移动端头像、徽章和统计卡片自动换行，统计更紧凑。
- 主按钮仍使用现有 `UiButton` / `--btn-primary-*` 体系，不改全局配色。

## Acceptance Criteria

- `/u/:username` 自己资料页能清楚看到更换头像、编辑资料、积分等级、徽章信任。
- `/u/:username` 他人资料页不展示编辑/头像上传入口。
- 页面在桌面与窄屏布局不出现右侧卡片横向溢出。
- 通过前端 typecheck。

## Technical Notes

- 主要改 `apps/web/src/pages/user/UserProfilePage.vue` 与同目录 SCSS。
- 可增加 `/me` 重定向入口和顶栏“个人中心”文案，提升发现性。
