## 美术语言

- 暖白底和深海军蓝轮廓，方形/阶梯转角、短距离硬投影。界面结构紧凑，避免堆叠多排同类圆角按钮。
- Hero使用静态粗字形 `Catalog Arcade Heading`，游戏名称在较窄区域使用较轻的 `Catalog Arcade Display`；两者基于已改名的OFL衍生字库，真实700字重并禁用字体合成。导航、按钮和正文仍用清晰的系统黑体，避免复杂小字拥挤。
- 主按钮仍读取 `--btn-primary-*`，实心 `#409EFF` 配白字。悬停和按下延续全站语义；不以渐变取代按钮。
- Hero 使用 `hero-v3.webp`，中央留白承载真实 HTML 标题与搜索。图片保持比例，按参考保留较大的摇杆及高楼，不把整页参考图当作界面。
- 卡片使用 `frame-card.png` 的透明九宫格卡匣边框，保留阶梯角、内高光和红色角钉；主按钮使用无色透明中心的 `button-frame.png`，蓝色仍由 CSS 变量提供。
- 保留正式 `/logo-lines-mark.png`、favicon 和真实游戏封面，不重绘、不像素化品牌或游戏图片。
- 普通图标来自 Pixelarticons 原始 MIT SVG。评分填充状态优先保留既有实心图标的清晰语义，不自行改造第三方路径。

## 页面结构

顶部导航与投稿入口、紧凑 Hero、个人范围/分类/排序工具栏、桌面两列横向游戏卡片。
手机重排为单列，所有主要操作保留至少 44px 点击区域和明确键盘焦点。

## 产品边界

所有游戏名称、作者、封面、评分、浏览量和热度来自现有目录。参考图里的样例数据不能作为产品事实。
想玩与最近打开保持已有本地保存规则；打开记录不表示实际游玩。
视觉改版不新增账号、分享、计时、成绩、详情页或自定义分类。

## 素材与验证

新素材位于 `apps/web/public/catalog/pixel-arcade/`，使用同源路径并随 Web 构建发布。
字体及图标的完整许可证、来源说明随资源保存；不引入新的 npm 依赖。被否定的Fusion字体仅保留在忽略的诊断目录，不能作为生产资源交付。
本地视觉对比采用选定图的实际尺寸及四款游戏状态，再检查 320/390/940/桌面布局和既有交互。
