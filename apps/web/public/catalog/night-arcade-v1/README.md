# 夜景掌机目录素材

2026-10-07 用户确认夜景掌机目录图。以下素材使用内置 image_gen 依据该图独立制作，搭配真实 DOM 控件，不包含完整页面 UI、Logo 或游戏封面替代品。

| 文件 | 用途 |
| --- | --- |
| hero-scene.webp | 夜景房间、电脑、猫、掌机与桌面，中央承载真实标题和搜索 |
| device-shell.webp | 中性掌机外壳，透明中央开窗，与八色变量混合 |
| yellow-button-frame.webp | 开始游戏按钮透明像素边框 |
| header-mascot.webp | 非交互站点装饰头像，无账号身份含义 |
| footer-scene.webp | 设备、书本、矮盆栽横带，无长植物/猫 |
| footer-cat.webp | 独立橘白猫、控制器与 GAME ON 小屏 |
| side-scene.webp | 卡片区两侧书架与植物，透明中央区域，页面只显示空白边缘 |

源 PNG、完整提示词与诊断保留在 Codex generated_images 和本地忽略目录，不随 Web 发布。正式 WebP 已压缩目检，透明素材保留 alpha。Logo、favicon、游戏封面、已有 OFL 字体和 MIT 图标继续使用现有资源，不生成替代品牌或占位游戏封面。

side-scene 使用内置 image_gen 依据同一确认稿生成，提示词保存在任务 diagnostics/side-scene-prompt.txt。目标为两侧窄书架和绿叶、深蓝夜景及青色高光；中央透明，不含 UI、文字、猫、Logo 或游戏封面。1536×1024 PNG 转为 WebP，保留透明通道，CSS 只展示 24px（手机 12px）边缘。
