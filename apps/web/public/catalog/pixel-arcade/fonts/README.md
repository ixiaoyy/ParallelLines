# 街机展示字体

用于目录大标题与游戏名称的短文本，不用于正文或表单内容。

## 来源与授权

- 原始字体：[ACh-K/Cubic-11 v1.500](https://github.com/ACh-K/Cubic-11/tree/v1.500)，来源文件 `fonts/ttf/Cubic_11.ttf`，内部源版本为1.451。
- 许可证：SIL Open Font License 1.1，完整原文见 `LICENSE-OFL.txt`。
- 衍生字体内部名称已改为 `ParallelLines Arcade Display`，保留原版权与许可证元数据，不以原字体保留名称发布。
- 此处为实际700字重文件；页面使用 `font-synthesis: none`，不依赖浏览器伪粗体。

## 文件

| 文件 | 用途 | 处理 |
|---|---|---|
| `arcade-heading.woff2` | 大标题、品牌短字和宽屏游戏名称 | E50：原网格向右、下各扩张50字体单位 |
| `arcade-display.woff2` | 较窄区域的游戏名称 | E25：扩张25字体单位，保留复杂字内部留白 |

源字体网格为100单位。每个原字形以隐藏名称保留，公开字形由原轮廓及三份平移轮廓组成，设置正确重叠标志。仅把汉字区原1300单位字宽改为1200，Latin、标点及其他宽度保持；完整保留原CMap，新增隐藏轮廓后共20,726字形。

字形构建由一次性fontTools工具完成，没有新增应用运行依赖。源TTF和WOFF2回读、字宽范围、字重、版权及浏览器实际加载均已检查。构建与小样记录保存在任务的字体研究目录。

发布时须同时保留本目录许可证。缺少字形或字体尚未加载时，界面回退到既有系统中文字体。
